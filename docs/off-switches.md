# Turning a change off

The short version, one line for each change, is in the [README](../README.md#turning-a-change-off). Below are the same switches with what each change does and what was measured. Settings you can change in the launcher are in [settings.md](settings.md).

Every change with a setting can be turned off without rebuilding: type the option under the launcher's *Advanced* → **More mcla.exe options**, or pass it to `mcla.exe`. If a problem goes away with a change off, please say which option did it in the [fork's issues](https://github.com/RenanQueiroz/mcla-recomp/issues).

With the option the update thread first waits on a high-resolution timer until the margin before the model's deadline (the previous frame's start plus 1,000,000 / the cap), then calls the driver as before, which spins the last stretch only.
